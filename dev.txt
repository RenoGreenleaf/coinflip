Each folder represents an entity type (except for "reusables" and "alembic"). An entity is an event, a publisher or a subscriber. It consists of a model, editor, and player. Either editor or player wrap a model to provide a user with access to it. Entities communicate with each other using events. For this reason all objects should be loaded in memory (so that not a single event be missed by a subscriber). Direct communication should be minimazed.
